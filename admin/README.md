# Admin (Vite + React + TypeScript)

Modern ecommerce admin template built with Vite.

## Run

```bash
cd /Users/ranjitredekar/Project/Ranjit/ecommerce/admin
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Screens

- Dashboard
- Products
- Orders
- Customers
- Settings
