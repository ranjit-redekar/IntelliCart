# Screenshots

Drop PNG captures here using the filenames the main [`README.md`](../../README.md) expects.

## Expected files

### Admin (web, desktop)
- `admin-dashboard.png` — `/dashboard`
- `admin-products.png` — `/products`
- `admin-new-product.png` — `/products/new` (with at least one image uploaded)
- `admin-orders.png` — `/orders`
- `admin-feedback.png` — `/feedback`
- `admin-promotions.png` — `/promotions`
- `admin-slides.png` — `/slides`
- `admin-signin.png` — `/sign-in`

### Customer Portal (web)
- `web-home.png` — `/`
- `web-shop.png` — `/shop` (try a smart search like "top-rated home goods under $80")
- `web-product.png` — `/products/P-1001` (any product)
- `web-cart.png` — `/cart` (with 2–3 items)
- `web-account.png` — `/account`
- `web-ai-assistant.png` — any page with the AI panel open

### Mobile (iOS Simulator or device)
- `mobile-home.png` — Shop tab
- `mobile-product.png` — any product detail
- `mobile-cart.png` — Cart tab with items
- `mobile-account.png` — Account tab signed in
- `mobile-ai.png` — AI assistant modal
- `mobile-search.png` — Search tab

## Capture tips

- **Web**: macOS `⇧⌘4` then drag a region, or use Chrome DevTools device toolbar to lock to a viewport (1440 × 900 for admin, 1280 × 800 for customer-web).
- **Mobile**: in the iOS Simulator, `⌘S` saves a PNG to your Desktop. Crop to the device frame or leave the status bar in.
- Keep filenames lowercase, hyphenated, `.png` extension. The README's `<img src>` tags will pick them up automatically.
